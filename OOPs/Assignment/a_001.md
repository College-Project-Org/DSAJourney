# OOP Assignment — Library Management System

A focused exercise on **encapsulation**, **abstraction**, and **method overloading** in Python.

> **Note:** This assignment intentionally excludes inheritance and method overriding. Those concepts are covered in a separate exercise.

---

## Concepts Covered

- **Encapsulation** — bundling data with the methods that operate on it, and controlling external access to internal state.
- **Abstraction** — exposing a simple interface while hiding implementation details.
- **Method Overloading (Pythonic style)** — a single method handling multiple call signatures via keyword arguments, since Python doesn't support traditional overloading.

---

## Problem Statement

Build a `Library` system that manages books. You'll create two classes: `Book` and `Library`.

### Class 1: `Book`

Represents a single book in the library.

#### Attributes

All attributes must be **encapsulated** (not directly accessible from outside the class):

| Attribute | Type | Constraint |
|-----------|------|------------|
| `title` | `str` | — |
| `author` | `str` | — |
| `isbn` | `str` | Must be exactly 13 digits |
| `copies_available` | `int` | Must never go below 0 |

#### Methods

| Method | Description |
|--------|-------------|
| `__init__(title, author, isbn, copies_available)` | Constructor. Validates `isbn` (13 digits) and `copies_available` (≥ 0). Raises `ValueError` if invalid. |
| `borrow()` | Decreases `copies_available` by 1. Raises `ValueError` if no copies are available. |
| `return_book()` | Increases `copies_available` by 1. |
| `title`, `author`, `isbn`, `copies_available` | Read-only properties (getters). |
| `__repr__()` | Returns a clean string representation of the book. |

---

### Class 2: `Library`

Manages a collection of books.

#### Requirements

1. Use an **encapsulated** internal storage structure (e.g., a dictionary mapping `isbn → Book`).
2. Clients should interact only through public methods — never touch the storage directly.

#### Methods

| Method | Description |
|--------|-------------|
| `add_book(book)` | Add a `Book` object to the library. |
| `remove_book(isbn)` | Remove a book by its ISBN. |
| `total_books()` | Return the total number of copies across all titles. |
| `search(...)` | **Overloaded method** — see below. |

#### Method Overloading: `search()`

Implement a **single `search()` method** that behaves differently based on the arguments passed:

| Call Signature | Behavior |
|----------------|----------|
| `search(isbn="...")` | Exact ISBN match. Returns a single `Book` or `None`. |
| `search(title="...")` | Case-insensitive partial match on title. Returns a list of `Book`s. |
| `search(author="...")` | Case-insensitive partial match on author. Returns a list of `Book`s. |
| `search(title="...", author="...")` | Match both filters. Returns a list of `Book`s. |

> Python doesn't support true method overloading like Java. The Pythonic way is to use optional keyword arguments and branch based on what's provided.

## Test Cases

Your implementation should pass the following test cases:

```python
lib = Library()
lib.add_book(Book("Clean Code", "Robert Martin", "9780132350884", 3))
lib.add_book(Book("The Pragmatic Programmer", "David Thomas", "9780135957059", 2))
lib.add_book(Book("Refactoring", "Martin Fowler", "9780134757599", 1))

# Search variations (method overloading)
print(lib.search(isbn="9780132350884"))
print(lib.search(title="clean"))
print(lib.search(author="martin"))
print(lib.search(title="programmer", author="thomas"))

# Borrow / return
book = lib.search(isbn="9780132350884")
book.borrow()
print(book.copies_available)  # Expected: 2

# Should fail — invalid ISBN
try:
    Book("Bad Book", "Someone", "123", 1)
except ValueError as e:
    print("Caught:", e)

# Should fail — borrow when 0 copies remain
b = Book("Solo", "X", "9999999999999", 1)
b.borrow()
try:
    b.borrow()
except ValueError as e:
    print("Caught:", e)
```

## Acceptance Criteria

Your solution is complete when:

- [ ] All `Book` attributes are encapsulated (prefixed with `_`) and exposed via `@property` getters.

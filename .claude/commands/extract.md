Run the project context extractor on a JSON file.

Usage: /extract <json_file_path>

Steps:
1. Activate the venv: `source env/bin/activate`
2. Run: `cd akash && python project_context_extractor.py $ARGUMENTS`
3. Report what summary file was written and show the first section of the output.

If no argument is provided, list available JSON files in the akash/ directory.
